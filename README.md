## 🛠️ Tech Stack

- **HTML5** – Structure
- **CSS3** – Styling and responsive layouts
- **JavaScript (ES6+)** – Logic and interactivity
- **DOM Manipulation** – Dynamic UI updates
- **Fetch API & REST APIs** – External data integration
- **LocalStorage** – Client-side data persistence

## 🧠 What I Practiced

- JavaScript fundamentals, functions, arrays and objects
- DOM manipulation and event handling
- ES6+ features and modern JavaScript
- Asynchronous programming (`Promises`, `async/await`)
- API integration and JSON handling
- Form validation and error handling
- Browser APIs and LocalStorage
- Problem-solving, debugging and code organization

## 🎯 The Goal

Build consistently, learn by doing, and turn concepts into working applications.

**Learn → Build → Debug → Improve**

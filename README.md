# 🚀 30 JavaScript Projects

A collection of **30 JavaScript projects** built step-by-step to strengthen my fundamentals through hands-on practice.

This repository is part of my journey to become a stronger software engineer by learning through **building, debugging, and improving**.

> **Learn → Practice → Build → Debug → Understand → Improve**

## 🎯 What I'm Building

The goal of this repository is simple:

**Build 30 projects. Understand the concepts behind them. Improve each project as my skills grow.**

The projects start with simple JavaScript fundamentals and gradually move toward DOM manipulation, browser APIs, LocalStorage, asynchronous JavaScript, and external APIs.

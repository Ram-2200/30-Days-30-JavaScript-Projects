# 30 Days • 30 JavaScript Projects

This repository is a hands-on JavaScript learning challenge consisting of **30 small projects built progressively from scratch**. Each project focuses on a practical problem or interaction that can be implemented using HTML, CSS, and vanilla JavaScript.

The purpose of this challenge is not to simply reproduce tutorial projects, but to use implementation as a way to strengthen JavaScript fundamentals. By building one project at a time, I am practicing how JavaScript interacts with the DOM, handles user input, manages application state, works with browser APIs, communicates with external APIs, and responds to real application requirements.

The projects will be added incrementally to the repository rather than uploaded all at once. As the challenge progresses, the applications will introduce more complex logic, asynchronous operations, APIs, validation, state management, and UI interactions.

> **Learn → Build → Debug → Understand → Improve**

---

## 🎯 Challenge Goals

The main goal of this challenge is to strengthen JavaScript fundamentals through repeated implementation rather than passive learning.

## 🧠 What I Will Learn

The projects collectively cover a broad set of JavaScript concepts. The purpose is to encounter these concepts repeatedly in different application contexts rather than treating them as isolated syntax exercises.

### JavaScript Fundamentals

I will practice:

- Variables and constants
- Data types
- Operators
- Type conversion
- Conditional statements
- Loops
- Functions
- Function parameters and return values
- Scope
- Arrays
- Objects
- Strings
- Numbers
- `Math`
- `Date`
- Random number generation
- Basic problem-solving logic

The goal is to become more comfortable translating a requirement into JavaScript logic.

### DOM Manipulation

I will practice working directly with web-page elements through JavaScript:

- Selecting elements
- Changing text and content
- Modifying classes
- Updating styles
- Creating elements dynamically
- Removing elements
- Updating lists and components
- Handling forms
- Reading user input
- Adding event listeners
- Responding to user interactions

### Modern JavaScript

As the projects progress, I will practice modern JavaScript features such as:

- Template literals
- Destructuring
- Spread and rest syntax

- Array methods such as `map`, `filter`, `find`, `reduce`, and `forEach`

Several projects depend on external APIs and therefore introduce asynchronous programming.

I will practice:

- Promises
- `async/await`
- Fetch API
- Handling asynchronous operations
- Loading states
- Successful responses
- Failed requests
- Network and API errors

### APIs and JSON

API-driven projects will provide practice with:

- HTTP requests
- REST APIs
- API endpoints
- Query parameters
- Fetching remote data
- JSON
- Parsing API responses
- Extracting relevant data
- Rendering API data in the UI

- Handling failed API requests

### Browser Storage

Projects such as the To-Do App will introduce client-side persistence using:

- `localStorage`
- Saving application state
- Reading stored data
- Updating stored data
- Removing stored data
- Converting between JavaScript objects/arrays and JSON

### Problem Solving

Every project provides an opportunity to practice:

- Breaking a problem into smaller parts
- Designing application logic

- Handling edge cases
- Validating user input
- Debugging unexpected behavior
- Testing different scenarios

## 🔨 Development Approach

Each project follows a similar development workflow while allowing the implementation to vary according to the problem.

1. **Understand the problem**  
   Identify what the application needs to do and what inputs and outputs are involved.

2. **Plan the UI and logic**  
   Break the application into smaller components, interactions, and logical steps.

3. **Build the HTML structure**  
   Create the elements required for the application's interface.

4. **Style the interface**  
   Build the layout and visual structure using CSS.

5. **Implement JavaScript functionality**  
   Connect user interactions and application logic to the DOM.

6. **Test the application**  
   Try normal inputs, invalid inputs, boundary cases, and different user interactions.

7. **Debug errors**  
   Use browser developer tools and debugging techniques to identify and fix problems.

8. **Refactor where necessary**  
   Improve duplicated logic, readability, organization, and maintainability where appropriate.

9. **Document what I learned**  
   Record the important concepts, implementation decisions, and possible improvements.

10. **Commit and push the project**  
    Add the completed work to GitHub as part of the ongoing challenge.

Projects are being added **incrementally**, one project at a time, rather than uploading all 30 projects together.
